# Keyword Language Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 68 hand-written card scripts (60 playable cards plus 8 helper spells) with declarative keyword cards that the engine runs and the UI prints, so card text is generated from the same data as behaviour and new cards are a list of keywords.

**Architecture:** A new `packages/cards/src/lang` module. A card is `card({ id, name, house, cost, type, target, keywords: [...] })`. Each keyword is plain serializable data (`{ kind: 'grant', ... }`) with a definition in a registry: how it compiles into the engine's existing `CardDef` hooks, how it prints (inline or on its own line), its glossary entry. `card()` merges every keyword's contribution (stat grants add up, event handlers chain, casting rules combine) into the same `CardDef` the engine already runs, so **the engine does not change**. A renderer prints the face text from the keywords. A `Script` keyword is the escape hatch for card-specific code and must carry its own text.

**Tech Stack:** TypeScript strict ESM, Vitest, npm workspaces. No new dependencies.

**User decisions (already made):**
- "we may even rewrite existing cards to conform to the framework using keywords. I don't like plain text cards that are too wordy as a list of instructions. Keywords are my preference."
- "Keywords generate the card text (Recommended)": keywords are the source of truth for both behaviour and printed text. The original wordy text stays only as a reference in `cards.json`. Mechanics stay faithful; presentation is new.
- "study the MTG keyword structure and we'll use that to guide us on the specific words to use." (see `docs/keyword-design.md`)
- "The vocabulary looks right. Write the keyword language plan using the proposed names."
- Scaffolding ("text to keywords" drafting tool) comes after this plan.

**Decisions made in this plan:**
1. Keywords are plain data, built with typed constructor functions (`Grant({ hand: 2 })`), so cards can be serialized, diffed, tested and later generated by a scaffolder.
2. **Face text layout** (MTG-like): line 1 is the target (`Swordsman.`); then all static keywords comma-joined on one line (`Truce, Lasts 3 turns.`); then each triggered or effect line in declaration order (`Start of turn: Heal 1 (group).`). Reminder text comes from the registry (glossary and tooltips), never from the card.
3. **Stat shorthand** in text matches the original stat lines: `+2 H` (hand), `+1 M` (missile), `+1 A` (armor), `+1 L` (level), `+4 HP`, `+1 Attack`.
4. Words from `docs/keyword-design.md` used here: `Flight`, `Desertwalk` and the other walks, `Concealed`, `Shroud`, `Warded`, `Pacified`, `Fleeting`, `Lasts N`, `Stackable`, `Truce`. New words this plan adds because the 60 cards need them: `Undispellable` (visible: false), `Concealment` (Fog of War), `Bound` (helper ends when terrain changes), `Afterwards` (spell becomes another when it expires), `Fanfare` (flavour-only music), `Rage` (ability word on the `Ramp` keyword), `Forbid` (restricts casting), and the effect verbs `Heal`, `Kill`, `Give` (cast a helper spell), `Expend` (dispel this spell), `Withdraw`.
5. `Unique`, `Ambush` and `Flurry N` from the vocabulary are not needed by the 60 existing cards; plan 2c (monsters and heroes) adds them.
6. **Migration is behaviour-preserving.** The existing card tests (157) run unchanged against the migrated cards and are the safety net; a new face-text test pins the printed text of every card, so wording changes are deliberate.
7. Cards that do not fit a keyword use `Script(text, fragment)` with hand-written text. Five cards do: Swashbuckler, Shattering Blow, Lienna's Steed, plus the two `Ramp` cards use the `Ramp` keyword (not Script).
8. Every migrated file keeps its path and default export (`export default card({...})`), so `src/war/index.ts` and `src/life/index.ts` do not change.

```ts
import type { CardDef, HouseId, ManaPool, SpellType, TargetType, TerrainId } from '@sanctum/engine';

/** What a keyword contributes to a card: any `CardDef` hook except the identity fields. */
export type Fragment = Partial<Omit<CardDef, 'id' | 'name' | 'house' | 'cost' | 'type' | 'target' | 'text'>>;

/** Keywords are plain data: `{ kind: 'grant', ... }`. Constructors in `keywords/*` build them. */
export interface Keyword {
  readonly kind: string;
}

/** `inline` keywords are comma-joined on one line after the target; `line` keywords get their own line. */
export interface PrintedPart {
  layout: 'inline' | 'line';
  text: string;
}

export interface TargetSpec {
  type: TargetType;
  friendly?: boolean;
  nonFriendly?: boolean;
  /** Minion class (recruit targets) or "group contains this class" (group targets). */
  cls?: 'swordsman' | 'archer';
  /** The minion must be alone in its group. */
  alone?: boolean;
  /** Square terrain required (square targets). */
  terrain?: TerrainId[];
}

export interface CompileCtx {
  target: TargetSpec;
  type: SpellType;
  cardId: string;
}

export interface KeywordDef<K extends Keyword = Keyword> {
  kind: K['kind'];
  /** Display name in the glossary. */
  term: string;
  /** core = learn first; house = per-house mechanic; oneoff = single-card rules. */
  tier: 'core' | 'house' | 'oneoff';
  /** Reminder text for the glossary and tooltips. */
  gloss: string;
  /** Printed form, or null to print nothing. */
  print(k: K): PrintedPart | null;
  /** What this keyword adds to the compiled card. */
  compile(k: K, ctx: CompileCtx): Fragment;
}

export interface CardSpec {
  id: string;
  name: string;
  house: HouseId;
  cost: Partial<ManaPool>;
  type: SpellType;
  helper?: boolean;
  target: TargetSpec;
  keywords: Keyword[];
}
```

```ts
import type { Keyword, KeywordDef } from './types';

const defs = new Map<string, KeywordDef<any>>();

export function defineKeyword<K extends Keyword>(def: KeywordDef<K>): KeywordDef<K> {
  if (defs.has(def.kind)) throw new Error(`duplicate keyword "${def.kind}"`);
  defs.set(def.kind, def);
  return def;
}

export function keywordDef(kind: string): KeywordDef<any> {
  const d = defs.get(kind);
  if (!d) throw new Error(`unknown keyword "${kind}"`);
  return d;
}

export const allKeywordDefs = (): Array<KeywordDef<any>> => [...defs.values()];
```

```ts
import type { StatDelta } from '@sanctum/engine';
import type { Fragment } from './types';

const NUMERIC = ['hand', 'missile', 'armor', 'maxHp', 'level', 'handAttacks', 'missileAttacks'] as const;

export function addStats(a: StatDelta, b: StatDelta): StatDelta {
  const out: StatDelta = { ...a };
  for (const k of NUMERIC) {
    if (b[k] !== undefined) out[k] = (out[k] ?? 0) + b[k]!;
  }
  if (b.walks) out.walks = [...(out.walks ?? []), ...b.walks];
  if (b.noDamage) out.noDamage = true;
  if (b.concealed) out.concealed = true;
  return out;
}

const present = <T>(xs: Array<T | undefined>): T[] => xs.filter((x): x is T => x !== undefined);

/** Combine keyword contributions into one set of `CardDef` hooks. */
export function mergeFragments(frags: Fragment[]): Fragment {
  const out: Fragment = {};

  const stats = present(frags.map((f) => f.stats));
  if (stats.length) out.stats = (q, id, sp) => stats.reduce((acc, f) => addStats(acc, f(q, id, sp)), {} as StatDelta);

  const canCast = present(frags.map((f) => f.canCast));
  if (canCast.length) out.canCast = (q, t) => canCast.every((f) => f(q, t));

  const persistent = present(frags.map((f) => f.persistent));
  if (persistent.length) out.persistent = (q, h) => persistent.every((f) => f(q, h));

  const blocks = present(frags.map((f) => f.blocksCast));
  if (blocks.length) out.blocksCast = (q, sp, a) => blocks.some((f) => f(q, sp, a));

  const onCast = present(frags.map((f) => f.onCast));
  if (onCast.length) out.onCast = (c, t) => onCast.forEach((f) => f(c, t));

  const onExpire = present(frags.map((f) => f.onExpire));
  if (onExpire.length) out.onExpire = (c) => onExpire.forEach((f) => f(c));

  const handlers = new Map<string, Array<(c: never, ev: never) => void>>();
  for (const f of frags) {
    for (const [type, fn] of Object.entries(f.on ?? {})) {
      if (!fn) continue;
      handlers.set(type, [...(handlers.get(type) ?? []), fn as (c: never, ev: never) => void]);
    }
  }
  if (handlers.size) {
    const on: NonNullable<Fragment['on']> = {};
    for (const [type, fns] of handlers) {
      (on as Record<string, (c: unknown, ev: unknown) => void>)[type] = (c, ev) =>
        fns.forEach((fn) => (fn as (c: unknown, ev: unknown) => void)(c, ev));
    }
    out.on = on;
  }

  for (const f of frags) {
    if (f.duration) out.duration = f.duration;
    if (f.bot) out.bot = f.bot;
    if (f.exclusive === false) out.exclusive = false;
    if (f.visible === false) out.visible = false;
    if (f.ignoresConcealment) out.ignoresConcealment = true;
    if (f.helper) out.helper = true;
  }
  return out;
}
```

```ts
import type { PlayerId, QueryContext, Ref, TargetType, TerrainId } from '@sanctum/engine';
import type { Fragment, TargetSpec } from './types';

const GROUP_TYPES: TargetType[] = ['recruitGroup', 'monsterGroup', 'group'];

export class TargetBuilder {
  constructor(readonly spec: TargetSpec) {}
  get friendly(): TargetBuilder {
    return new TargetBuilder({ ...this.spec, friendly: true });
  }
  get nonFriendly(): TargetBuilder {
    return new TargetBuilder({ ...this.spec, nonFriendly: true });
  }
  get alone(): TargetBuilder {
    return new TargetBuilder({ ...this.spec, alone: true });
  }
  with(cls: 'swordsmen' | 'archers'): TargetBuilder {
    return new TargetBuilder({ ...this.spec, cls: cls === 'swordsmen' ? 'swordsman' : 'archer' });
  }
  on(...terrain: TerrainId[]): TargetBuilder {
    return new TargetBuilder({ ...this.spec, terrain });
  }
}

export const Target = {
  globe: new TargetBuilder({ type: 'globe' }),
  group: new TargetBuilder({ type: 'group' }),
  recruitGroup: new TargetBuilder({ type: 'recruitGroup' }),
  recruit: new TargetBuilder({ type: 'recruit' }),
  swordsman: new TargetBuilder({ type: 'recruit', cls: 'swordsman' }),
  archer: new TargetBuilder({ type: 'recruit', cls: 'archer' }),
  square: new TargetBuilder({ type: 'square' }),
  structure: new TargetBuilder({ type: 'structure' }),
};

export const toTargetSpec = (t: TargetSpec | TargetBuilder): TargetSpec => (t instanceof TargetBuilder ? t.spec : t);

const ownerOf = (q: QueryContext, ref: Ref): PlayerId | undefined =>
  ref.kind === 'minion' ? q.minion(ref.id)?.owner
  : ref.kind === 'group' ? q.group(ref.id)?.owner
  : ref.kind === 'structure' ? q.structure(ref.id)?.owner
  : undefined;

/** The casting requirements a target spec implies, as a `canCast`. */
export function targetFragment(t: TargetSpec): Fragment {
  const checks: Array<(q: QueryContext, ref: Ref) => boolean> = [];
  if (t.friendly) checks.push((q, r) => ownerOf(q, r) === q.caster);
  if (t.nonFriendly) checks.push((q, r) => ownerOf(q, r) !== q.caster);
  if (t.cls && (t.type === 'recruit' || t.type === 'minion' || t.type === 'monster')) {
    checks.push((q, r) => r.kind === 'minion' && q.minion(r.id)?.cls === t.cls);
  }
  if (t.cls && GROUP_TYPES.includes(t.type)) {
    checks.push((q, r) => r.kind === 'group' && q.minionsOf(r.id).some((m) => m.cls === t.cls));
  }
  if (t.alone) {
    checks.push((q, r) => {
      const m = r.kind === 'minion' ? q.minion(r.id) : undefined;
      return !!m && q.minionsOf(m.groupId).length === 1;
    });
  }
  if (t.terrain) {
    checks.push((q, r) => r.kind === 'square' && t.terrain!.includes(q.terrainAt(r.pos) as TerrainId));
  }
  return checks.length ? { canCast: (q, r) => checks.every((f) => f(q, r)) } : {};
}

const cap = (s: string) => s.charAt(0).toUpperCase() + s.slice(1);
const lowerFirst = (s: string) => s.charAt(0).toLowerCase() + s.slice(1);

/** "Friendly recruit group." / "Swordsman alone in its group." / "Forest square." ... */
export function printTarget(t: TargetSpec): string {
  if (t.type === 'globe') return 'Globe.';
  let noun: string;
  switch (t.type) {
    case 'recruit': noun = t.cls ? cap(t.cls) : 'Recruit'; break;
    case 'monster': noun = 'Monster'; break;
    case 'minion': noun = 'Minion'; break;
    case 'recruitGroup': noun = 'Recruit group'; break;
    case 'monsterGroup': noun = 'Monster group'; break;
    case 'group': noun = 'Group'; break;
    case 'structure': noun = 'Town or colony'; break;
    default: noun = t.terrain ? `${cap(t.terrain.join(' or '))} square` : 'Square';
  }
  if (t.cls && GROUP_TYPES.includes(t.type)) noun += ` with ${t.cls}s`;
  if (t.alone) noun += ' alone in its group';
  const prefix = t.friendly ? 'Friendly ' : t.nonFriendly ? 'Non-friendly ' : '';
  return `${prefix ? prefix + lowerFirst(noun) : noun}.`;
}
```

```ts
  const spec: CardSpec = {
    id: input.id, name: input.name, house: input.house, cost: input.cost, type: input.type,
    helper: input.helper, target: toTargetSpec(input.target), keywords: input.keywords,

  for (const k of spec.keywords) {
    frags.push(keywordDef(k.kind).compile(k, { target: spec.target, type: spec.type, cardId: spec.id }));
  }

    id: spec.id, name: spec.name, house: spec.house, cost: spec.cost, type: spec.type, target: spec.target.type,
    ...mergeFragments(frags),
  };
  if (spec.helper) def.helper = true;
  return def;
```

```ts
import { specOf } from './card';
import { allKeywordDefs, keywordDef } from './registry';
import { printTarget } from './target';
import type { CardSpec } from './types';

export interface Face {
  id: string;
  name: string;
  lines: string[];
}

/** Target line, then inline keywords comma-joined, then line keywords in declaration order. */
export function renderSpec(spec: CardSpec): Face {
  const inline: string[] = [];
  const lines: string[] = [];
  for (const k of spec.keywords) {
    const part = keywordDef(k.kind).print(k);
    if (!part) continue;
    (part.layout === 'inline' ? inline : lines).push(part.text);
  }
  const out = [printTarget(spec.target)];
  if (inline.length) out.push(`${inline.join(', ')}.`);
  out.push(...lines);
  return { id: spec.id, name: spec.name, lines: out };
}

export function faceOf(id: string): Face | undefined {
  const spec = specOf(id);
  return spec ? renderSpec(spec) : undefined;
}

/** "Thermite Damage (-1 A)": a helper spell's name and its text, for use inside another card's text. */
export function helperSummary(id: string): string {
  const spec = specOf(id);
  if (!spec) return id;
  const body = renderSpec(spec).lines.slice(1).map((l) => l.replace(/\.$/, '')).join('; ');
  return body ? `${spec.name} (${body})` : spec.name;
}

export interface GlossaryEntry {
  kind: string;
  term: string;
  tier: 'core' | 'house' | 'oneoff';
  gloss: string;
}

const TIER_ORDER = { core: 0, house: 1, oneoff: 2 } as const;

export function glossary(): GlossaryEntry[] {
  return allKeywordDefs()
    .map((d) => ({ kind: d.kind, term: d.term, tier: d.tier, gloss: d.gloss }))
    .sort((a, b) => TIER_ORDER[a.tier] - TIER_ORDER[b.tier] || a.term.localeCompare(b.term));
}
```

```ts
/** Stat grants. `to` limits who gets them; `heal` also raises current hp by the max hp granted (target minion). */
export const Grant = (stats: GrantStats, opts: { to?: GrantTo; heal?: boolean } = {}): GrantKeyword => ({
  kind: 'grant', stats, to: opts.to ?? 'all', heal: opts.heal ?? false,
});

const ORDER = ['hand', 'missile', 'armor', 'level', 'maxHp', 'attacks'] as const;
const LABEL = { hand: 'H', missile: 'M', armor: 'A', level: 'L', maxHp: 'HP', attacks: 'Attack' } as const;
const SUBJECT: Record<GrantTo, string> = { all: '', swordsmen: 'Swordsmen ', archers: 'Archers ', enemies: 'Enemy recruits ' };

function appliesTo(to: GrantTo, m: Minion, spell: ActiveSpell): boolean {
  switch (to) {
    case 'swordsmen': return m.cls === 'swordsman';
    case 'archers': return m.cls === 'archer';
    case 'enemies': return m.kind === 'recruit' && m.owner !== spell.owner;
    default: return true;
  }
}

function toDelta(s: GrantStats, m: Minion): StatDelta {
  const d: StatDelta = {};
  if (s.hand !== undefined) d.hand = s.hand;
  if (s.missile !== undefined) d.missile = s.missile;
  if (s.armor !== undefined) d.armor = s.armor;
  if (s.level !== undefined) d.level = s.level;
  if (s.maxHp !== undefined) d.maxHp = s.maxHp;
  if (s.attacks !== undefined) {
    if (m.cls === 'archer') d.missileAttacks = s.attacks;
    else d.handAttacks = s.attacks;
  }
  return d;
}
```

```ts
import type { EventContext, GameEvent, Minion, Ref } from '@sanctum/engine';

/** Which minions an effect applies to, relative to the spell's host, the event, or the cast target. */
export type Scope =
  | 'host' | 'hostGroup' | 'hostGroupHurtOther' | 'hostOccupants'
  | 'victim' | 'enterer' | 'created' | 'opponent'
  | 'allBoard' | 'allRecruits'
  | 'target' | 'targetEach' | 'targetDamaged';

export const SCOPE_PHRASE: Record<Scope, string> = {
  host: '', hostGroup: ' (group)', hostGroupHurtOther: ' (most hurt ally)', hostOccupants: ' (recruits here)',
  victim: ' (victim)', enterer: ' (entering group)', created: ' (new recruit)', opponent: ' (opposing group)',
  allBoard: ' (all minions)', allRecruits: ' (all recruits)',
  target: '', targetEach: ' (each)', targetDamaged: ' (each damaged)',
};

export function hostGroupId(c: EventContext): number | undefined {
  const h = c.host;
  if (h.kind === 'group') return h.id;
  if (h.kind === 'minion') return c.minion(h.id)?.groupId;
  return undefined;
}

export function resolveScope(c: EventContext, ev: GameEvent | undefined, scope: Scope, target?: Ref): number[] {
  const members = (gid: number | undefined): number[] => (gid === undefined ? [] : c.minionsOf(gid).map((m) => m.id));
  const onBoard = (m: Minion) => m.status === 'alive' && !!c.group(m.groupId)?.pos;
  switch (scope) {
    case 'host':
      return c.host.kind === 'minion' ? [c.host.id] : [];
    case 'hostGroup':
      return members(hostGroupId(c));
    case 'hostGroupHurtOther': {
      const me = c.host.kind === 'minion' ? c.minion(c.host.id) : undefined;
      if (!me) return [];
      const hurt = c.minionsOf(me.groupId)
        .filter((m) => m.id !== me.id && m.kind === 'recruit' && m.hp < m.maxHp)
        .sort((a, b) => b.maxHp - b.hp - (a.maxHp - a.hp))[0];
      return hurt ? [hurt.id] : [];
    }
    case 'hostOccupants': {
      const st = c.host.kind === 'structure' ? c.structure(c.host.id) : undefined;
      const g = st ? c.groupAt(st.pos) : undefined;
      return g && g.kind === 'recruit' ? members(g.id) : [];
    }
    case 'victim': {
      const id = ev?.data.victimId;
      return typeof id === 'number' && c.minion(id) ? [id] : [];
    }
    case 'enterer':
      return members(ev?.ref?.kind === 'group' ? ev.ref.id : undefined);
    case 'created': {
      const id = ev?.data.minionId;
      return typeof id === 'number' ? [id] : [];
    }
    case 'opponent': {
      const id = ev?.data.opponent;
      return typeof id === 'number' ? members(id) : [];
    }
    case 'allBoard':
      return Object.values(c.state.minions).filter(onBoard).map((m) => m.id);
    case 'allRecruits':
      return Object.values(c.state.minions).filter((m) => onBoard(m) && m.kind === 'recruit').map((m) => m.id);
    case 'target':
      return target?.kind === 'minion' ? [target.id] : [];
    case 'targetEach':
      return target?.kind === 'minion' ? [target.id] : target?.kind === 'group' ? members(target.id) : [];
    case 'targetDamaged':
      return resolveScope(c, ev, 'targetEach', target).filter((id) => {
        const m = c.minion(id);
        return !!m && m.hp < m.maxHp;
      });
  }
}
```

```ts
import { helperSummary } from './render';
import { resolveScope, SCOPE_PHRASE, type Scope } from './scopes';

export type Effect =
  | { kind: 'heal'; amount: number | 'full'; scope: Scope }
  | { kind: 'damage'; amount: number; scope: Scope }
  | { kind: 'kill'; scope: Scope }
  | { kind: 'terraform'; terrain: TerrainId; area: 'target' | 'adjacent' | 'contiguous'; from?: TerrainId }
  | { kind: 'expend' }
  | { kind: 'dispelAll' }
  | { kind: 'mana'; mana: ManaType; amount: number; to: 'caster' | 'structureOwner' }
  | { kind: 'give'; card: string; scope: Scope; once: boolean }
  | { kind: 'giveSquares'; card: string; terrain: TerrainId }
  | { kind: 'withdraw' }
  | { kind: 'moveTwice' }
  | { kind: 'randomMove' }
  | { kind: 'cancelMoves' };

export const Heal = (amount: number | 'full', scope: Scope = 'host'): Effect => ({ kind: 'heal', amount, scope });
export const Damage = (amount: number, scope: Scope = 'host'): Effect => ({ kind: 'damage', amount, scope });
export const Kill = (scope: Scope = 'host'): Effect => ({ kind: 'kill', scope });
export const Terraform = (terrain: TerrainId, area: 'target' | 'adjacent' | 'contiguous' = 'target', from?: TerrainId): Effect => ({ kind: 'terraform', terrain, area, from });
/** "Expend": dispel this spell. */
export const Expend = (): Effect => ({ kind: 'expend' });
export const DispelAll = (): Effect => ({ kind: 'dispelAll' });
export const AddMana = (mana: ManaType, amount: number, to: 'caster' | 'structureOwner' = 'caster'): Effect => ({ kind: 'mana', mana, amount, to });
/** Cast a helper spell on each minion in scope. `once` skips minions that already have it. */
export const Give = (card: string, scope: Scope, once = false): Effect => ({ kind: 'give', card, scope, once });
export const GiveSquares = (card: string, terrain: TerrainId): Effect => ({ kind: 'giveSquares', card, terrain });
export const Withdraw = (): Effect => ({ kind: 'withdraw' });
export const MoveTwice = (): Effect => ({ kind: 'moveTwice' });
export const RandomMove = (): Effect => ({ kind: 'randomMove' });

const hasSpellOnMinion = (c: EventContext, card: string, id: number) =>
  c.state.spells.some((sp) => sp.cardId === card && sp.host.kind === 'minion' && sp.host.id === id);

export function runEffect(c: EventContext, ev: GameEvent | undefined, e: Effect, target?: Ref): void {
  switch (e.kind) {
    case 'heal':
      for (const id of resolveScope(c, ev, e.scope, target)) c.heal(id, e.amount === 'full' ? 999 : e.amount);
      return;
    case 'damage':
      for (const id of resolveScope(c, ev, e.scope, target)) c.damage(id, e.amount);
      return;
    case 'kill':
      for (const id of resolveScope(c, ev, e.scope, target)) c.kill(id);
      return;
    case 'terraform': {
      if (e.area === 'target') {
        if (target?.kind === 'square') c.setTerrain(target.pos, e.terrain);
      } else if (e.area === 'adjacent') {
        const st = target?.kind === 'structure' ? c.structure(target.id) : undefined;
        if (st) for (const d of ADJACENT) c.setTerrain({ x: st.pos.x + d.x, y: st.pos.y + d.y }, e.terrain);
      } else if (target?.kind === 'square' && e.from) {
        for (const p of contiguous(c, target.pos, e.from)) c.setTerrain(p, e.terrain);
      }
      return;
    }
    case 'expend':
      c.dispel();
      return;
    case 'dispelAll': {
      if (target?.kind !== 'group') return;
      const gid = target.id;
      const members = new Set(c.minionsOf(gid).map((m) => m.id));
      for (const sp of [...c.state.spells]) {
        if (!sp.visible) continue; // non-visible spells cannot be dispelled
        const h = sp.host;
        if ((h.kind === 'group' && h.id === gid) || (h.kind === 'minion' && members.has(h.id))) c.dispel(sp.id);
      }
      return;
    }
    case 'mana': {
      if (e.to === 'caster') {
        const owner = c.spell.owner;
        if (owner !== 'neutral') c.addMana(owner, e.mana, e.amount);
      } else {
        const st = c.host.kind === 'structure' ? c.structure(c.host.id) : undefined;
        if (st && st.owner !== 'neutral') c.addMana(st.owner, e.mana, e.amount);
      }
      return;
    }
    case 'give':
      for (const id of resolveScope(c, ev, e.scope, target)) {
        if (e.once && hasSpellOnMinion(c, e.card, id)) continue;
        c.createSpell(e.card, { kind: 'minion', id });
      }
      return;
    case 'giveSquares': {
      if (target?.kind !== 'square') return;
      for (const p of contiguous(c, target.pos, e.terrain)) {
        const has = c.state.spells.some(
          (sp) => sp.cardId === e.card && sp.host.kind === 'square' && sp.host.pos.x === p.x && sp.host.pos.y === p.y,
        );
        if (!has) c.createSpell(e.card, { kind: 'square', pos: p });
      }
      return;
    }
    case 'withdraw':
      c.endCombat();
      return;
    case 'moveTwice':
      if (target?.kind === 'group') c.setMovesTwice(target.id);
      return;
    case 'randomMove': {
      if (target?.kind !== 'group' || c.group(target.id)?.control !== 'player') return;
      const dirs = c.legalDirections(target.id);
      if (dirs.length > 0) c.setMoveOrder(target.id, dirs[Math.floor(c.random() * dirs.length)]);
      return;
    }
    case 'cancelMoves':
      for (const g of Object.values(c.state.groups)) {
        if (g.kind !== 'recruit') continue;
        c.setMoveOrder(g.id, null);
        c.setMovesTwice(g.id, false);
      }
      return;
  }
}

const cap = (s: string) => s.charAt(0).toUpperCase() + s.slice(1);

export function printEffect(e: Effect): string {
  switch (e.kind) {
    case 'heal': return `Heal ${e.amount === 'full' ? 'full' : e.amount}${SCOPE_PHRASE[e.scope]}`;
    case 'damage': return `${e.amount} damage${SCOPE_PHRASE[e.scope]}`;
    case 'kill': return `Kill${SCOPE_PHRASE[e.scope]}`;
    case 'terraform':
      return e.area === 'adjacent' ? `Adjacent squares become ${e.terrain}`
        : e.area === 'contiguous' ? `Contiguous ${e.from} becomes ${e.terrain}`
        : `Square becomes ${e.terrain}`;
    case 'expend': return 'Expend';
    case 'dispelAll': return 'Dispel all (target group)';
    case 'mana': return `+${e.amount} ${cap(e.mana)}${e.to === 'structureOwner' ? ' (owner)' : ''}`;
    case 'give': return `Give ${helperSummary(e.card)}${SCOPE_PHRASE[e.scope]}`;
    case 'giveSquares': return `Give ${helperSummary(e.card)} to contiguous ${e.terrain}`;
    case 'withdraw': return 'Withdraw';
    case 'moveTwice': return 'Move twice';
    case 'randomMove': return 'Random direction';
    case 'cancelMoves': return 'Cancel all moves';
  }
}
```

```ts
import type { EventContext, EventType, GameEvent } from '@sanctum/engine';
import { isHostMinion } from '../helpers';
import { hostGroupId } from './scopes';

export type Trigger =
  | { when: 'startOfTurn' }
  | { when: 'startOfCombat'; against?: 'monster' }
  | { when: 'eachRound'; round?: number }
  | { when: 'afterAllCombat' }
  | { when: 'beforeMovement' }
  | { when: 'manaPhase' }
  | { when: 'enter'; group?: 'recruit' }
  | { when: 'created' }
  | { when: 'onHit' }
  | { when: 'onDamage'; victim?: 'monster' };

export const When = {
  startOfTurn: { when: 'startOfTurn' } as Trigger,
  startOfCombat: (against?: 'monster'): Trigger => ({ when: 'startOfCombat', against }),
  eachRound: (round?: number): Trigger => ({ when: 'eachRound', round }),
  afterAllCombat: { when: 'afterAllCombat' } as Trigger,
  beforeMovement: { when: 'beforeMovement' } as Trigger,
  manaPhase: { when: 'manaPhase' } as Trigger,
  enter: (group?: 'recruit'): Trigger => ({ when: 'enter', group }),
  created: { when: 'created' } as Trigger,
  onHit: { when: 'onHit' } as Trigger,
  onDamage: (victim?: 'monster'): Trigger => ({ when: 'onDamage', victim }),
};

export function triggerEvent(t: Trigger): EventType {
  switch (t.when) {
    case 'startOfTurn': return 'turn:start';
    case 'startOfCombat': return 'combat:start';
    case 'eachRound': return 'round:start';
    case 'afterAllCombat': return 'turn:afterCombat';
    case 'beforeMovement': return 'movement:before';
    case 'manaPhase': return 'mana:generate';
    case 'enter': return 'group:enter';
    case 'created': return 'minion:created';
    case 'onHit': return 'attacker:hits';
    case 'onDamage': return 'attacker:damages';
  }
}

export function triggerLabel(t: Trigger): string {
  switch (t.when) {
    case 'startOfTurn': return 'Start of turn';
    case 'startOfCombat': return `Start of combat${t.against ? ' (vs monsters)' : ''}`;
    case 'eachRound': return t.round === undefined ? 'Each round' : `Round ${t.round}`;
    case 'afterAllCombat': return 'After all combat';
    case 'beforeMovement': return 'Before movement';
    case 'manaPhase': return 'Mana';
    case 'enter': return `On enter${t.group ? ' (recruit group)' : ''}`;
    case 'created': return 'Recruit created';
    case 'onHit': return 'On hit';
    case 'onDamage': return `On damage${t.victim ? ' (monster)' : ''}`;
  }
}

/** Group events matter only for the host's own group; a spell on the globe or a structure sees every group. */
const groupMatches = (c: EventContext, ev: GameEvent): boolean => {
  if (ev.ref?.kind !== 'group') return false;
  const hg = hostGroupId(c);
  return hg === undefined || hg === ev.ref.id;
};

export function triggerApplies(c: EventContext, ev: GameEvent, t: Trigger): boolean {
  switch (t.when) {
    case 'startOfCombat': return groupMatches(c, ev) && (!t.against || c.group(ev.data.opponent)?.kind === 'monster');
    case 'eachRound': return groupMatches(c, ev) && (t.round === undefined || ev.data.round === t.round);
    case 'enter': {
      const g = ev.ref?.kind === 'group' ? c.group(ev.ref.id) : undefined;
      return !!g && (!t.group || g.kind === 'recruit');
    }
    case 'onHit': return isHostMinion(c, ev);
    case 'onDamage': return isHostMinion(c, ev) && (!t.victim || c.minion(ev.data.victimId)?.kind === 'monster');
    default: return true;
  }
}
```

```ts
export interface OnKeyword extends Keyword {

  trigger: Trigger;
  effects: Effect[];
}
/** "<Trigger>: effect, effect." Runs the effects whenever the trigger's event happens for this spell's host. */
export const On = (trigger: Trigger, ...effects: Effect[]): OnKeyword => ({ kind: 'on', trigger, effects });

defineKeyword<OnKeyword>({
  kind: 'on', term: 'Triggers', tier: 'core',
  gloss: 'A trigger runs its effects every time its event happens for the spell\'s host: start of turn, start of combat, each round, after all combat, before movement, the mana phase, a group entering, a recruit being created, a hit or damage dealt.',
  print: (k) => ({ layout: 'line', text: `${triggerLabel(k.trigger)}: ${k.effects.map(printEffect).join(', ')}.` }),
  compile: (k) => {
    const on: NonNullable<Fragment['on']> = {};
    on[triggerEvent(k.trigger)] = (c, ev) => {
      if (!triggerApplies(c, ev, k.trigger)) return;
      for (const e of k.effects) runEffect(c, ev, e);
    };
    return { on };
  },
});
```

```ts
import type { QueryContext, TargetType } from '@sanctum/engine';
import { GROUP_TARGETS, hasEnchantments, INDIVIDUAL_TARGETS } from '../../helpers';
import { defineKeyword } from '../registry';
import type { Keyword } from '../types';

export type SpellClass = 'globe' | 'structure' | 'group' | 'individual';

const classOf = (t: TargetType): SpellClass | undefined =>
  t === 'globe' ? 'globe'
  : t === 'structure' ? 'structure'
  : GROUP_TARGETS.includes(t) ? 'group'
  : INDIVIDUAL_TARGETS.includes(t) ? 'individual'
  : undefined;

/* ---------- Forbid ---------- */

export interface ForbidKeyword extends Keyword {
  kind: 'forbid';
  spells: SpellClass[];
  by?: 'caster';
  friendly: boolean;
}
/** While active, spells of these classes cannot be cast. `by: 'caster'` limits it to this spell's caster; `friendly` to targets that caster owns. */
export const Forbid = (spells: SpellClass[], opts: { by?: 'caster'; friendly?: boolean } = {}): ForbidKeyword => ({
  kind: 'forbid', spells, by: opts.by, friendly: opts.friendly ?? false,
});

defineKeyword<ForbidKeyword>({
  kind: 'forbid', term: 'Forbid', tier: 'house',
  gloss: 'While this lasts, spells of the named classes cannot be cast; they squander. Globe, structure, group and individual spells are the classes.',
  print: (k) => {
    const base = `${k.spells.join(' or ')} spells`;
    const text = k.by === 'caster'
      ? `Caster: no ${base}${k.friendly ? ' on friends' : ''}.`
      : `No ${base}.`;
    return { layout: 'line', text };
  },
  compile: (k) => ({
    blocksCast: (q, sp, a) => {
      const cls = classOf(a.card.target);
      if (!cls || !k.spells.includes(cls)) return false;
      if (k.by === 'caster' && a.caster !== sp.owner) return false;
      if (k.friendly) {
        const owner = a.target.kind === 'group' ? q.group(a.target.id)?.owner
          : a.target.kind === 'minion' ? q.minion(a.target.id)?.owner
          : undefined;
        if (owner !== sp.owner) return false;
      }
      return true;
    },
  }),
});

/* ---------- Shroud ---------- */

export interface ShroudKeyword extends Keyword {
  kind: 'shroud';
  from: Array<'group' | 'individual'>;
  against?: 'friendly';
}
/** The host (a group or a minion) cannot be targeted by group and/or individual spells. */
export const Shroud = (opts: { from?: Array<'group' | 'individual'>; against?: 'friendly' } = {}): ShroudKeyword => ({
  kind: 'shroud', from: opts.from ?? ['group', 'individual'], against: opts.against,
});

defineKeyword<ShroudKeyword>({
  kind: 'shroud', term: 'Shroud', tier: 'house',
  gloss: 'Cannot be targeted by the named kinds of spell (group spells aimed at the group, individual spells aimed at its members). Optionally only by friendly casters.',
  print: (k) => {
    const q = [k.against === 'friendly' ? 'friendly' : '', k.from.length === 2 ? '' : k.from[0]].filter(Boolean).join(' ');
    return { layout: 'inline', text: q ? `Shroud (${q} spells)` : 'Shroud' };
  },
  compile: (k) => ({
    blocksCast: (q: QueryContext, sp, a) => {
      const cls = classOf(a.card.target);
      if (cls !== 'group' && cls !== 'individual') return false;
      if (!k.from.includes(cls)) return false;
      const host = sp.host;
      let hostGroupId: number | undefined;
      let hostMinionId: number | undefined;
      let owner;
      if (host.kind === 'group') {
        hostGroupId = host.id;
        owner = q.group(host.id)?.owner;
      } else if (host.kind === 'minion') {
        const m = q.minion(host.id);
        hostMinionId = host.id;
        hostGroupId = m?.groupId;
        owner = m?.owner;
      } else {
        return false;
      }
      if (k.against === 'friendly' && a.caster !== owner) return false;
      if (cls === 'group') return a.target.kind === 'group' && a.target.id === hostGroupId;
      if (a.target.kind !== 'minion') return false;
      return hostMinionId !== undefined ? a.target.id === hostMinionId : q.minion(a.target.id)?.groupId === hostGroupId;
    },
  }),
});

/* ---------- Warded ---------- */

export interface WardedKeyword extends Keyword {
  kind: 'warded';
  reduce?: number;
}
/** Combat damage from recruits without enchantments is cancelled after armor; `Warded(n)` reduces it by n before armor instead. */
export const Warded = (reduce?: number): WardedKeyword => ({ kind: 'warded', reduce });

defineKeyword<WardedKeyword>({
  kind: 'warded', term: 'Warded', tier: 'house',
  gloss: 'Takes no combat damage from recruits without enchantments (after armor). "Warded N": damage from them is reduced by N before armor.',
  print: (k) => ({ layout: 'inline', text: k.reduce === undefined ? 'Warded' : `Warded ${k.reduce}` }),
  compile: (k) => {
    const attackerOf = (c: import('@sanctum/engine').EventContext, id: unknown) =>
      id == null ? undefined : c.minion(id as number);
    if (k.reduce === undefined) {
      return {
        on: {
          'armor:after': (c, ev) => {
            if (ev.ref?.kind !== 'minion' || c.host.kind !== 'minion' || ev.ref.id !== c.host.id) return;
            const attacker = attackerOf(c, ev.data.attackerId);
            if (attacker && attacker.kind === 'recruit' && !hasEnchantments(c, attacker)) c.cancel();
          },
        },
      };
    }
    return {
      on: {
        'attack:beforeArmor': (c, ev) => {
          if (ev.ref?.kind !== 'minion' || c.host.kind !== 'minion' || ev.ref.id !== c.host.id) return;
          const attacker = attackerOf(c, ev.data.attackerId);
          if (attacker && attacker.kind === 'recruit' && !hasEnchantments(c, attacker)) ev.data.damage -= k.reduce!;
        },
      },
    };
  },
});

/* ---------- Concealment ---------- */

export interface ConcealmentKeyword extends Keyword {
  kind: 'concealment';
}
/** Every minion is concealed from both sides. */
export const Concealment = (): ConcealmentKeyword => ({ kind: 'concealment' });
defineKeyword<ConcealmentKeyword>({
  kind: 'concealment', term: 'Concealment', tier: 'house',
  gloss: 'While active, every minion is Concealed from both sides: individual spells cannot target any minion (spells that ignore concealment still can).',
  print: () => ({ layout: 'line', text: 'All minions are Concealed.' }),
  compile: () => ({
    blocksCast: (_q, _sp, a) => classOf(a.card.target) === 'individual' && !a.card.ignoresConcealment,
  }),
});
```

```ts
import { isHostMinion } from '../../helpers';
import { defineKeyword } from '../registry';
import type { Fragment, Keyword } from '../types';

/* ---------- Ramp (the Rage mechanic) ---------- */

export interface RampKeyword extends Keyword {
  kind: 'ramp';
  per: 'hit' | 'casualty';
  cap?: number;
}
/**
 * Rage: grows +1 H until the end of the combat. `Ramp('hit')`: each time the host minion is hit.
 * `Ramp('casualty', cap)`: each death in the host group during combat, up to `cap`.
 */
export const Ramp = (per: 'hit' | 'casualty', cap?: number): RampKeyword => ({ kind: 'ramp', per, cap });

const capped = (n: number, cap?: number) => (cap === undefined ? n : Math.min(cap, n));

defineKeyword<RampKeyword>({
  kind: 'ramp', term: 'Rage', tier: 'house',
  gloss: 'Ability word for a damage bonus that grows during a combat and resets when it ends.',
  print: (k) => ({
    layout: 'line',
    text: k.per === 'hit'
      ? 'Rage: +1 H each time hit, until end of combat.'
      : `Rage: +1 H per casualty${k.cap === undefined ? '' : ` (max +${k.cap})`}, until end of combat.`,
  }),
  compile: (k) =>
    k.per === 'hit'
      ? {
          stats: (_q, _id, spell) => ({ hand: spell.tokens.rage ?? 0 }),
          on: {
            'attack:hit': (c, ev) => {
              if (isHostMinion(c, ev)) c.setToken('rage', capped(c.token('rage') + 1, k.cap));
            },
            'combat:end': (c) => {
              c.setToken('rage', 0);
            },
          },
        }
      : {
          stats: (_q, _id, spell) => ({ hand: spell.tokens.casualties ?? 0 }),
          on: {
            'combat:start': (c) => {
              c.setToken('fighting', 1);
            },
            // Any death during combat counts, including instant kills (ctx.kill, blame null).
            'minion:dies': (c) => {
              if (c.token('fighting') === 1) c.setToken('casualties', capped(c.token('casualties') + 1, k.cap));
            },
            'combat:end': (c) => {
              c.setToken('casualties', 0);
              c.setToken('fighting', 0);
            },
          },
        },
});

/* ---------- Script (escape hatch) ---------- */

export interface ScriptKeyword extends Keyword {
  kind: 'script';
  text: string;
  fragment: Fragment;
}
/** Card-specific rules that fit no keyword. Must carry its own printed `text`; prefer a keyword when one exists. */
export const Script = (text: string, fragment: Fragment): ScriptKeyword => ({ kind: 'script', text, fragment });

defineKeyword<ScriptKeyword>({
  kind: 'script', term: 'Special rule', tier: 'oneoff',
  gloss: 'A rule that only this card has; the card prints it in full.',
  print: (k) => ({ layout: 'line', text: k.text }),
  compile: (k) => k.fragment,
});
```
